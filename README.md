# 🛒 KDS Super Market Sales Analytics Dashboard

## 📌 Project Overview

The KDS Super Market Sales Analytics project analyzes supermarket sales and profitability using SQL Server and Microsoft Power BI. The dashboard provides an interactive view of business performance and helps users understand sales trends, order growth, costs, and profit.

## 🎯 Project Objectives

* Analyze overall supermarket sales performance.
* Monitor revenue, orders, profit, quantity, and cost.
* Track growth percentages and business performance.
* Identify monthly sales trends.
* Enable interactive data analysis using slicers.
* Present business insights through an interactive dashboard.

## 🛠️ Tools & Technologies

* **SQL Server** — Data storage and SQL queries.
* **Microsoft Power BI** — Data visualization and dashboard development.
* **DAX** — KPI calculations and growth percentage measures.
* **Power BI Slicers** — Interactive filtering and analysis.

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPI cards:

* Total Revenue
* Total Orders
* Total Profit
* Total Quantity
* Total Cost
* Growth Percentage Measures

## 📈 Dashboard Features

* Interactive KPI cards.
* Monthly revenue trend analysis.
* Sales performance visualizations.
* Interactive slicers for filtering data.
* Profit and cost analysis.
* Business performance monitoring.
